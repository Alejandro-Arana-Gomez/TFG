🏋️ FitLife
Aplicación Android para la gestión personalizada de dietas y rutinas de entrenamiento

FitLife es una aplicación Android desarrollada como Trabajo de Fin de Grado en Ingeniería Informática en la Universidad de Cantabria.

La aplicación permite al usuario gestionar su alimentación y entrenamiento desde un mismo lugar, creando dietas, comidas, alimentos, rutinas y ejercicios personalizados.

✨ Funcionalidades
🥗 Gestión de alimentación
Crear y gestionar dietas personalizadas.
Organizar las dietas por días.
Crear, editar y eliminar comidas.
Añadir ingredientes a las comidas.
Gestionar alimentos y sus valores nutricionales.
Seguimiento de calorías, proteínas, carbohidratos y grasas.
🏋️ Gestión de rutinas
Crear y gestionar rutinas de entrenamiento.
Organizar las rutinas por días.
Añadir y eliminar ejercicios.
Buscar ejercicios.
Filtrar ejercicios por grupo muscular.
Consultar información e imágenes de los ejercicios.
👤 Gestión del usuario
Registro de usuarios.
Inicio de sesión.
Gestión del perfil.
Gestión de dietas y rutinas asociadas al usuario.

🏗️ Arquitectura

La aplicación Android utiliza una arquitectura basada en el patrón MVVM (Model-View-ViewModel).

La aplicación se comunica con un backend desarrollado con Spring Boot mediante una API REST, encargado de gestionar los usuarios, dietas, comidas, alimentos, rutinas y ejercicios.
